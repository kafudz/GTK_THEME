# GTK_THEME

Basic GTK themes.

| Path | Contents |
| --- | --- |
| [`MyTheme/`](MyTheme/README.md) | GTK2 / GTK3 / GTK4 theme with dark and light variants |
| `PKGBUILD` | Arch Linux package: `makepkg -si` installs `MyTheme` and `MyTheme-Light` |
| `scripts/check.py` | Static sanity checks for the theme (run before committing) |
